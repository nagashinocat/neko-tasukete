# ちょっと、うちの猫ちゃんを助けてあげて

猫は、宇宙にいる。約1万段積み上がっただるまを、ゲージのタイミングに合わせて叩き落とし、てっぺんの猫ちゃんを助けにいくスマホ向けブラウザゲーム。

## 遊び方

- 画面のどこかをタップすると、一番下の段が抜ける
- ゲージの針が真ん中(赤い帯)に来たときに叩くと「ぴったり!」。だるまの傾きが戻る
- ずれて叩くと、ずれた分だけだるまが傾く。傾きが限界を超えると崩れて終わり
- 抜くほど針が速くなる。到達した段数がスコア。結果はカード画像で共有できる

## ローカルで動かす

```sh
python3 -m http.server 8000
# http://localhost:8000/ を開く
```

## テスト

```sh
node --test tests/*.test.js
```

## 調整

針の速さ、ぴったりの幅、傾きの溜まり方、景色が変わる段数などは `src/config.js` にまとめてある。

## 公開

GitHub Pages(ブランチのルート)でそのまま動く。`index.html` の `og:url`・`og:image` は公開URLに合わせて書き換える。
