# だるま落としタイミングゲーム 設計書

作成日: 2026-11-17 / 仮タイトル: だるま落とし(正式名は未定)

## 1. ねらい(なぜ作るか)

だるま落としを、スマホで遊べるタイミングゲームにする。
遊びの芯は **「テンポと難しさがどんどん上がっていく緊張感」**。
1回のプレイで「どこまで登れるか」に挑み、結果を友だちと見せ合う。

舞台のスケール感が売り:だるまは約1万段積み上がっていて、**頭は宇宙にある**。
普通の人は宇宙まで届かない。頭を見られた人は「伝説」。

## 2. 目標 / やらないこと / 失敗の条件

### 目標
- 1回のタップの気持ちよさより、**速くなるテンポに指が追いつくかのハラハラ**が主役
- 「傾いてきた、立て直さなきゃ」という持ちこたえる時間を作る
- 結果カードを見せ合いたくなる
- 自己ベストを超えたくなり、何度もやり直したくなる

### やらないこと(今回は作らない)
- 全体ランキング・サーバー
- 途中から続きを遊ぶ(セーブして何日もかけて登る)機能
- ちょっと笑える設定やストーリー(シンプルなだるま落としにする。あとで足す可能性はある)
- 3D表示

### 失敗の条件(動いても、これなら失敗)
- 叩いたのに反応が遅れる/タイミング判定がずれる(「ちゃんと叩いたのに」と感じさせる)
- テンポが上がってもスマホでカクつく
- 序盤が退屈、または序盤から難しすぎてすぐ終わる

## 3. 制約

- スマホのブラウザで遊ぶ(縦画面)。PCブラウザでも遊べるとよい
- サーバーなし。GitHub Pages で公開(新しいリポジトリ)
- リンク共有時に画像(OGP)が出るとよい(既存作品と同じ方針)

## 4. 作り方の候補(Approaches)

| 案 | 中身 | 長所 | 短所 |
|---|---|---|---|
| **A. 2D(HTML+Canvas)** ← 採用 | 平面のイラスト風に描く | 軽い・反応が速い・画面に映る十数段だけ描けばよい | 見上げる遠近感は出しにくい |
| B. 3D | 立体で下から見上げる | 迫力がある | 速いテンポで反応が遅れる心配、手間が増える |
| C. ゲーム用ライブラリ(Phaser等) | 道具に乗る | 演出を作りやすい | この規模には重い |

**A を採用(本人が了承)。** 芯が「テンポに指が追いつくか」なので、反応の速さと軽さを優先。
オープニングはまっすぐ下へのスクロールで、背景の多層スクロールで奥行きを出す。
斜めに見上げる絵は不要と本人が判断したため3Dにしない。

## 5. 本人が決めたこと

### 遊び方
- だるまが約**1万段**積み上がっている。頭は宇宙
- 画面下の**ゲージ**の針が往復し、真ん中の帯に来た瞬間にタップすると一番下の段がポンと抜ける
- 抜くたびに**テンポがどんどん上がる**(針が速くなる)
- だるまは左右に揺れる(**揺れは見た目の演出**。タイミングはゲージで取る)
- **1回のプレイで挑む**。1万段は事実上届かない目標

### 外したとき
- ずれた分だけだるまが**傾き**、ずれが溜まると崩れて終了
- ぴったりで叩くと傾きが**戻る**(立て直せる)
- タップすれば**どこで叩いても一番下の段は抜け、段数は進む**(テンポを止めない)
- 傾きの増え方は、真ん中からのずれに比例する。適当に連打するとすぐ傾きが溜まって崩れる
- 帯の中心にある狭い「ぴったり」範囲で叩くと傾きが戻る
- 針が通り過ぎてもタップしなければ何も起きない

### 高さの見せ方
- 背景の移り変わりは1万段に比例させず、**序盤ほど早く、上ほどゆっくり**変わる
  - 目安:100段で空 → 500段で雲の上 → 2,000段で成層圏 → 宇宙は1万段の頂上のみ(数値は調整可)
  - ふつうの人でも2〜3回は景色が変わるようにする

### 記録と共有
- スコア = 到達した段数
- **自己ベスト**をスマホに保存
- **結果カード**(画像つき、例「3,482段まで到達!」)を作ってSNS・LINEで共有

### オープニング
- 宇宙にぽつんと浮かぶだるまの頭の画面から始まる
- 画面が下へスクロール(宇宙 → 地球の縁 → 雲を突き抜ける → 地上)し、地上で止まってゲーム開始

## 6. 提案として決めたこと(本人未確認の作り手判断)

- 遊んでいる間、画面のはしに「宇宙まであと 9,873段」のような目安を出す
- 登るほど背景が地上→空→雲→成層圏→宇宙と変わり、高さを感じさせる
- 言語は日本語
- オープニングのスクロールは初回だけ全部流し、2回目以降は短くするかタップで飛ばせるようにする(「何度もやり直したくなる」とぶつからないように)

## 7. 作り手に任せること

- ゲージの帯の幅、針の速さの上がり方、傾きの溜まり方・戻り方の数値(試遊で調整する前提)
- だるまの絵柄・色・音・効果音
- 結果カードの見た目と画像の作り方
- 崩れるときの演出
- ファイル構成、リポジトリ名

## 追加仕様(2026-11-17):コンボとアイテムルーレット段

### コンボ(実装済み)
- 「ぴったり」が続いた回数がコンボ。ずれたら0
- 10コンボごとに1回で飛ぶ段が1つ増える(10コンボで2段、20で3段…上限10段)

### ルーレット段
- 金色に光る段が30〜60段に1回まざる
- 槌で叩いて抜くとゲームが一時停止し、ルーレットが回る。タップするとだんだん遅くなって止まる(完全には狙えない)
- 爆弾・ミサイルで吹き飛んだルーレット段はルーレットを回さない

### アイテム(6種、同じ確率)
| アイテム | 効果 |
|---|---|
| 爆弾 | 下から10段が吹き飛ぶ |
| ミサイル | 下から30段を貫いて飛ばす |
| お守り | 次に1回外しても、コンボが切れず傾きも増えない |
| 砂時計 | 次の10回、針がゆっくりになる |
| ペンキ(いたずら) | 画面にインクが3〜4か所飛び散り、次の10回のあいだ残る。叩くたびに少しずつ薄れる。ゲージに少しかかることもある |
| のり(いたずら) | 上の10段がくっつき、1段につき2回叩かないと抜けない。1回目は「ペリッ」とはがれるだけ。判定とコンボはふつうに数える。のりの段があるあいだはコンボのまとめ飛ばしはお休み |
